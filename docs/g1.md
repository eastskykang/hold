# Retargeted trajectories for G1

We provide motion trajectories retargeted for the Unitree G1 robot, based on 80%-scale BVH animations.
The trajectories were generated with the kinematic motion retargeting algorithm used in the [ZEST](https://www.science.org/doi/10.1126/scirobotics.aec7695) and [HuMBLE](https://arxiv.org/abs/2610.10489) projects.

The retargeted trajectories are stored in HDF5 (H5) format. They can be loaded with standard HDF5 libraries such as [h5py](https://www.h5py.org/) and viewed in the browser with [myHDF5](https://myhdf5.hdfgroup.org/).

We also provide a simple [MuJoCo](https://mujoco.org/)-based visualizer that plays these trajectories on the G1 robot (see [Getting started with the visualizer](#getting-started-with-the-visualizer)). It uses the 29-DoF [Unitree G1 model from MuJoCo Menagerie](https://github.com/google-deepmind/mujoco_menagerie/tree/main/unitree_g1), which is downloaded automatically on first use.

We are also developing a Blender plugin for visualizing, editing, and photorealistically rendering these trajectories. It has not been released yet.

## Data format

Each H5 file stores the trajectory under `robot_data/trajectory_data`:
- `time`: timestamps in seconds.
- `joints/{labels,pos,vel}`: the 29 joint positions and velocities. The joint order is given by `joints/labels` and differs between files, so always map joints by name.
- `bodies/{labels,pos_w,quat_w,lin_vel_w,ang_vel_w}`: world-frame body poses and velocities, with `[w, x, y, z]` quaternions.

Note that the `base` body corresponds to the frame of the G1 `torso_link`, not the pelvis.

## Getting started with the visualizer

Install the dependencies in your Python environment:
```bash
pip install -r visualizer/requirements.txt
```

Run the visualizer:
```bash
python visualizer/visualize_g1.py data/g1/locomotion/walk                      # play every motion in a directory
python visualizer/visualize_g1.py data/g1/locomotion/sprint/s0_sprint_001.h5  # play a single file
```

Playback follows the timestamps stored in each file, so it runs in real time by default. Use `--speed` to change the initial speed.

| Key | Action |
|-----|--------|
| `Space` | Pause/resume |
| `N` / `P` | Next/previous motion |
| `R` | Restart the current motion |
| `Z` / `X` | Slower/faster |
