# Retargeted trajectories for G1

We provide motion trajectories retargeted for the Unitree G1 robot, based on 80%-scale BVH animations.
The trajectories were generated with the kinematic motion retargeting algorithm used in the [ZEST](https://www.science.org/doi/10.1126/scirobotics.aec7695) and [HuMBLE](https://arxiv.org/abs/2610.10489) projects.

The retargeted trajectories are stored in HDF5 (H5) format. They can be loaded with standard HDF5 libraries such as [h5py](https://www.h5py.org/), and viewed in the browser with [myHDF5](https://myhdf5.hdfgroup.org/).
We are currently developing a software tool to visualize these trajectories on the G1 robot's morphology.
